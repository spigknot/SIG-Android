  Onde eu coloquei: em ggml_vk_op_get_pipeline(), que escolhe o PIPELINE a
  usar para o nó RMS_NORM.

  são FUNDIDAS no grafo.

  Medição que expôs o erro (mesmo prompt, Q4 oficial, mesmo aparelho):

    configuração                    argmax   saída

  Ou seja: o contorno FUNCIONA (all-off dá o texto certo) mas o MEU GATE

  foi planejada. Meu return era ignorado.

  A saída "gr子 pac□主度度ruit上帝..." é o TEXTO REAL PRODUZIDO pelo aparelho
  com o gate no lugar errado. Não é ilustração: é o log.
