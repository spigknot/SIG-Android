  Os três padrões usam pipelines DIFERENTES, mas compilados do MESMO shader

    pipeline_rms_norm_mul_rope_f32_f16     ← "rms_norm_mul_rope_f32_f16"
  Dentro de rms_norm.comp, o caminho RMS+MUL é o bloco `do_multiply`
  (linhas 88-103), exatamente onde a reprodução reproduz avg_err=5.11457:
    linha 88:  if (do_multiply) {
