4.2 Modos de execucao
-----------------------------------------------------------
A Activity decide o modo (linhas 519-540):

  smartInsertViable = jobConfig.smartInsertChecked
                     && isSmartInsertCodecSupported(profile)
  fullReencode = (reencode && (!smartInsert || transition != NONE))
                 || (isWav && !canCopyDirectly)
                 || (smartInsert && !smartInsertViable)
  Sem fullReencode + smartInsertChecked:
                 -> executeSmartInsert (recodifica so o pedaco
                    inserido, copia o resto bit-a-bit, concat)
  Sem fullReencode + !smartInsertChecked + canCopyDirectly:
                 -> executeCopyInsert (concat bit-a-bit, sem
                    nenhuma recodificacao)
  Senão:
                 -> error("áudios incompatíveis") ou
                    buildFullReencodeArguments (re-encoda ambos)

  isSmartInsertCodecSupported (980-995): alac/flac/pcm/wav/vorbis/
  opus/aac. COBRENCIA boa.

4.3 Encoder escolhido
-----------------------------------------------------------
  encoderForProfile(extension, profile) (992-1006):
    alac -> alac
    flac -> flac
    pcm/wav -> pcm_s16le
    vorbis -> libvorbis
    opus -> libopus
    mp3 -> libmp3lame
    aac -> aac
    ext=ogg/opus -> vorbis ou opus (depende do codec original)
    senao -> encoderForExtension(ext)
              mp3/flac/ogg/opus/wav/senao->aac

  Para o Smart Insert, o middle file usa encoderForProfile.
  Para Copy, e' -c copy. Verifique: as extensoes aceitas no
  Copy estao em SUPPORTED_COPY_EXTENSIONS (m4a, aac, mp3, wav,
  flac, ogg, opus) — bate.

  Verificacao OK. Sem bugs aqui.

Localizacao: FfmpegInsertAudioActivity.kt:653-655
